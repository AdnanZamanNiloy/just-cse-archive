# Hotel Management System

The Hotel Management System is a Java-based application that allows users to manage hotel reservations, including reserving 
rooms, viewing current reservations, getting room  numbers, updating reservations, deleting  reservations, adding new rooms,
and removing existing rooms.

## Features

1. **Room Management**:
   - The system has a list of rooms, each with a unique room number and a status of either "reserved" or "available".
   - Users can view the current status of all rooms in the hotel.

2. **Reservation Management**:
   - Users can reserve rooms by  providing the  guest's name,  contact number, and the  number of rooms to reserve.
   - The system will automatically assign available rooms to the reservation and update their status to "reserved".
   - Users can view a list of all current reservations, including the reservation ID, guest name, room number, and
   - contact number.

3. **Reservation Update and Deletion**:
   - Users can update existing reservations, including changing the guest's name, room number, and contact number.
   - Users can also delete reservations, which will free up the reserved rooms for future bookings.

4. **Room Addition and Removal**:
   - Users can add new rooms to the system, as long as the room number is unique.
   - Users can also remove existing rooms, as long as the room is not currently reserved.

5. **User Interface**:
   - The system provides a command-line interface for users to interact with the hotel management features.
   - Users  can navigate through the various options by  selecting  the corresponding number from the menu.

## How to Use

1. Run the `HotelReservationSystem` class to start the application.
2. Follow the on-screen instructions to access the different features of the Hotel Management System.
3. When you're done, select the "Exit" option to close the application.

## Conclusion

The Hotel  Management System is  a versatile and user-friendly application that can help hotel owners and managers efficiently
managetheir hotel's reservations and room inventory. With its various features, the system makes it easy to keep track of room 
availability, make reservations, and update or delete them as needed.
