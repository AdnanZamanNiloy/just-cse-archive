# University Academic Resources

Organized academic resources for university coursework.

## Structure

Each semester is a top-level directory:

- `semester-1-2`
- `semester-2-1`
- `semester-2-2`
- `semester-3-1`
- `semester-3-2`
- `semester-4-1`

Inside each semester, resources are grouped by subject. Course materials may contain folders such as `lecture-slides`, `notes`, `assignments`, `lab`, `previous-questions`, and `additional-materials`.

Generated IDE files, build output, temporary files, and backup files are excluded through `.gitignore`.

## GitHub note

This collection is larger than GitHub's recommended repository size, and individual files larger than 100 MB cannot be pushed through ordinary Git. Check large files before pushing and use Git LFS or a separate cloud archive where necessary.
